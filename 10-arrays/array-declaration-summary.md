# 다양한 배열 선언 방법 정리

## 1) 선언만 (기본값으로 초기화)
`var nums [5]int`  
- 결과: `[0 0 0 0 0]`

## 2) 선언과 동시에 초기화
`days := [3]string{"monday", "tuesday", "wednesday"}`

## 3) 일부 값만 초기화 (나머지는 기본값)
`var temps [5]float64 = [5]float64{24.3, 26.7}`  
- 결과: `[24.3 26.7 0 0 0]`  
- `float64` 기본값은 `0.0`

## 4) 인덱스 지정 초기화 (타입은 우변으로 추론)
`var s = [5]int{1: 10, 3: 30}`  
- 결과: `[0 10 0 30 0]`

## 5) 길이 자동 추론 배열
`x := [...]int{10, 20, 30}`  
- 타입은 `[3]int` (배열 길이 고정)

## 배열 vs 슬라이스
`[3]int{10, 20, 30}` : 배열(길이 고정)  
`[]int{10, 20, 30}` : 슬라이스(길이 가변)

- 배열은 길이가 타입에 포함됨 (`[3]int`와 `[5]int`는 다른 타입)
- 슬라이스는 길이가 타입에 포함되지 않음 (`[]int`)

## 한 줄 요약
- `[...]T{...}` 는 **배열 길이 자동 추론**
- `[]T{...}` 는 **슬라이스 생성**
